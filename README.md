# LangChainLab
A collection of examples and reusable "recipes" for the LangChain framework.

## Overview

This repo will be a guide / reference to the Langchain framework that will contain:

1. **Examples**: Working implementations of features from the Langchain documentation
2. **Recipes**: Reusable patterns and workflows built with multiple Langchain components
3. **Utils**: Any needed helper functions and common patterns

## Structure

- `/examples` - Individual examples demonstrating Langchain features
- `/recipes` - Reusable patterns and workflows
- `/utils` - Utility functions and helpers
